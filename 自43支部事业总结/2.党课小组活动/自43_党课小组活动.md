| 活动地点 | 线上 | 参加人数 | 8 |
| 活动内容概要 | 本次活动围绕国家人口发展战略、生育支持政策体系以及社会婚育观念演变等核心议题，组织同学们对多份详实的文献与报道进行了深度阅读与研讨。 |  |  |
| 活动总结 | 本次阅读研讨活动具有很强的时代意义与现实价值。随着我国人口老龄化程度加深和出生人口持续下降，低生育率问题已成为全社会关注的焦点。<br>首先，生育问题不仅仅是个人和家庭的选择，更是关乎国家长远发展的战略性问题。破解低生育率陷阱，不能仅靠单一呼吁，而是需要像两会代表委员们所建议的那样，依靠系统性的政策设计，从顶层制度、资金保障、公共服务等多个维度协同发力。<br>其次，构建生育友好型社会需要全社会的观念革新。无论是治理网络空间中刻意制造的性别对立与生育焦虑，还是倡导破除高价彩礼等陈规陋习的新型婚育文化，亦或是保障劳动者的休息权、承认女性生育的社会价值，都是为年轻人敢于恋爱、步入婚姻、组建家庭扫除障碍。<br>最后，通过国际视角的对比，同学们拓宽了思考的维度。各国在应对人口问题时所采取的不同路径与经验教训，为我们理解本国政策的演进提供了宝贵的参考框架。整体而言，本次活动有效引导了同学们从宏观政策和微观人本的双重角度，理性、客观地看待当下的婚育议题。 |  |  |

| 活动主题 | 深根——清明祭扫 | 活动时间 | 2026.4.5 |
| --- | --- | --- | --- |
| 活动地点 | 清华英烈纪念碑 | 参加人数 | 5 |
| 活动内容概要 | 在烽火连天的革命年代，无数清华先烈浴血奋战，以铮铮铁骨践行誓言。2026年，适逢清华党组织建立100周年。为缅怀先烈、传承红色基因，自43党课小组于4月5日清明节当天，前往水木清华北山之阴的清华英烈纪念碑，开展了庄严肃穆的清明祭扫活动。 |  |  |
| 活动总结 |  同学们身着素装整齐列队，向清华英烈纪念碑深鞠躬并敬献白菊，以跨越百年的精神对话表达对先辈的无尽哀思与崇高敬意。集体聆听志愿者讲解，学习包括沈崇诲在内的清华英烈舍生取义的壮烈事迹。在已知65名清华英烈（含33位共产党员）的峥嵘岁月感召下，深刻体悟清华人一脉相承的爱国奉献精神。 |  |  |
| 同学感想 | 黄洺希：昨天展板上有一位叫沈崇诲的先烈，让我印象非常深刻。小时候看电影《无问西东》，这部电影记录了不同时代的清华人在中国历史上的不同贡献。电影里有个片段让我久久不能忘怀：清华出身的飞行员沈光耀在弹药耗尽后，决绝地驾机撞向敌舰。原来，沈崇诲先生正是他的历史原型。昨天的祭扫经历让我意识到那不仅仅是电影里的催泪桥段，更是前辈们真真切切的青春与抉择。<br>张潇文：又是一年清明，来到清华英烈纪念碑前，心里满是崇敬和感慨。献上白菊的那一刻，看着碑上铭刻的历史，听着志愿者讲述各位英烈的事迹，我更真切地感受到我们如今的和平生活是这些年轻的先烈们用生命和热血换来的。他们年纪与我们相仿，也各自有充实的生活，真实的爱好，但表现出了超乎常人的勇气和担当，为了国家和民族，义无反顾地献出了自己的一切。作为他们的学弟学妹们，我们倍感荣幸，也明白传承他们的爱国精神不是一句口号。今后我们当以他们为榜样，踏实做事、心怀家国，不辜负先烈们的牺牲和付出，创造中国新的奇迹。<br>李锦：<br>清华党组织建立100周年的清明，我们来到清华英烈纪念碑前，缅怀先烈。志愿者向我们讲述着英雄们的光荣事迹，前辈们在国家需要之时挺身而出，用血肉与生命守护人民。园子内春机盎然，行人旅客享受着满园春色，我想，这正是百年之前的前辈们所期盼的。遥想百年之后，这世界又会是怎样一番图景呢？我想，这份责任徐徐落在了我们的肩头。吾辈青年当将青春与家国联系在一起，用行动去书写属于新时代的崭新篇章。 |  |  |
