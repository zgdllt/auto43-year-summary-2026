| 团日前期工作 | 提前分组进行问卷或访谈调查，请大家收集周围人（同龄人，学长学姐，老师，家长）对于科研的一些看法，包括但不限于为什么要参加科研？科研的意义和目的是什么？什么样的人才算做出了点东西？<br>加入一个问题，在面对一个大作业/比赛时，你可以选择沿用学长的经验，求稳拿结果；也可以从头自己来过，一鸣惊人或者颗粒无收，你会选择哪一个？为什么？<br>预约教室，邀请嘉宾<br>制作PPT<br>在班级公众号上预热宣传 |  |  |
| 团日现场流程 | 环节一：主题引入（5min）<br>针对《S.H.I.T》期刊以及相关事件做一个解释说明，让大家都对它有一个更为清楚的认知（观看创始人当时建立网站的视频，抓取一些《S.H.I.T》上关注度比较高的论文） |  |  |
|  | 环节二：暖场小游戏——学术黑话翻译（5min）<br>邀请同学们针对日常生活中非常常见的生活场景或者生活问题，将其“翻译”为“学术黑话”，例如（熬夜打游戏导致第二天早八起不来->《虚拟空间沉浸式交互对青年群体昼夜节律及物理空间出勤率的负向干预机制》）,或者让同学们根据后者猜出前者。 |  |  |
|  | 环节三：评价体系的异化（20min）<br>从《S.H.I.T》这种更偏向娱乐的期刊，转向现实中真实存在的异化的评价体系。列举一些真实的事件（比如用土豆伪造肿瘤的这种学术造假，然后一些小学生的科研竞赛出现了硕博的课题，或者现在高中生开始发表论文等）。通过这些例子，反思评价体系对于意义本身的侵蚀，对于古德哈特定律：当一个指标被当成目标时，它就不再是一个好指标。”有更为深刻的理解。<br>邀请同学们对于前期调查的问题进行下讨论分享，了解周围人对于科研，学术研究究竟需要做什么做出一些分享。这个部分可能需要适调查的情况做出一些相应的调整。<br>制作PPT的时候也要尽可能地融入问卷的内容，串联起来。<br>观看视频，了解江晓源教授对于影响因子游戏的一些看法。（此处的视频作为一个可选项吧，把更多的时间用在讨论和分享上面。） |  |  |
|  | 环节四：青年学者的生存困境（20min）<br>从科研当中拓展到我们的日常生活当中，分析从高中到大学，大学毕业后可能是工作，考公，留校等等，但是这个过程中都多少存在对于评价体系的迎合。举例子的话可以有对于实践评奖之类的讨论。<br>在这个地方也展示先前对在大作业/比赛的时候选择求稳还是创新的方法的问卷调查，作为一个简单的引入。再邀请同学们讨论分享，自己在日常生活中是否会被各种kpi所影响，导致自己真正的思考无处安放，举一些例子。<br>分析“形式主义”对意义的剥夺，如哲学家韩炳哲在《倦怠社会》中提到，现代人的疲惫不是因为身体劳累，而是因为我们在做大量“缺乏内在意义感”的事情。<br>此时邀请同学们去思考，什么东西是确确实实困住我们的，什么东西是我们自己困住自己的，又如何去实现“带着镣铐跳舞”呢？ |  |  |
|  | 环节五：互联网时代的解构力量（10min）<br>狂欢之后怎么办： 这种象征性的反抗确实很爽，但“爽完之后”呢？青年人如何在这种解构之后，重新去建构有意义的评价体系呢？<br>1案例分析：<br>可以拿一些案例，比如搞笑诺贝尔奖宗旨是“先让你大笑，然后再让你思考”。比如研究“为什么猫是液体”、“啄木鸟为什么不会头痛”。这是一种良性的解构，打破了学术的刻板印象，但依然保留了对真理的探求。<br>或者可以放B站UP主用meme来讲解一些道理。他们夺回了“知识解释权”，让知识不再被垄断在象牙塔的期刊里。<br>这个地方可以结合时政，比如最近谈到很多的“正确的政绩观”。如何建构正确的“科研观”“学习观”“生活观”。<br>2结构后的重构：<br>如果现在，将评价体系交还给我们自己，你会如何制定一个合理的评价体系呢？（可以提供一些具体的方向，比如学术，保研，实践等等，尽量贴近同学们的生活，反思如何有一个好的指标。） |  |  |
|  | 环节六：狂欢背后的自我清醒（5min）<br>我们固然没有办法直接对一些现行体系做出改变，但我们心中应该有一把不同于外在准则的标尺，去衡量自己所做之事的目的以及意义。<br>发放一些明信片或者信纸，邀请大家写下一个不考虑一切评价体系，确确实实希望解决或者弄清楚的问题，无论方向，无论领域，无论课题，主题团日后他们将被妥善保存，等到毕业再发放。 |  |  |
|  | 环节七：嘉宾点评（5min）<br>邀请辅导员和老师针对自己的科研或者生活经历进行分享，对同学们进行相应的指导以及引领。 |  |  |
| 团日亮点 | 从最近互联网热点出发，分析一场狂欢背后引人深思的地方。同学们进入大二下，或多或少会接触到科研，也希望借此机会能够让同学们对科研有更为深刻的认知。同时，团日从科研出发，但不仅仅局限于科研，而是广泛分析日常生活中极为常见的形式主义困境，同时邀请大家反思现状，提出一些可行的建议，并尝试在评价体系之外为自己无处安放的思考寻找栖息之所。 |  |  |
